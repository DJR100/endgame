# Product Requirement Documents (PRDs)

This directory contains detailed specifications for each core feature of the EndGambling app:

- [Panic Button](prd_panic_button.md) - Emergency intervention feature
- [Guided Calm](prd_guided_calm.md) - Breathing and hypnosis exercises
- [Streak Counter](prd_streak_counter.md) - Tracking bet-free days
- [Community CTA](prd_community_cta.md) - Discord community integration

Each PRD includes detailed requirements, development steps, and testing criteria.
